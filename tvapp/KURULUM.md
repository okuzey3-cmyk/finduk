# Sinema Odasi - Samsung TV uygulamasi

Bu klasor, Samsung TV'ye kurulacak uygulamanin kaynagidir (Tizen web uygulamasi).
Icinde gizli bilgi yoktur. Finduk'un adresi TV'de ilk acilista yazilir.

## Kurulum ozeti (bilgisayarda)
1. Tizen Studio'yu kur (Samsung TV Extension ile).
2. TV'de: Uygulamalar > 12345 yaz > Gelistirici modu Acik, bilgisayarin IP'sini yaz, TV'yi yeniden baslat.
3. Tizen Studio: File > Import > Tizen > Tizen Project > bu "tvapp" klasorunu sec.
4. Device Manager'dan TV'yi ekle (IP), Certificate Manager'dan Samsung sertifikasi olustur.
5. Projeye sag tikla > Run As > Tizen Web Application.
